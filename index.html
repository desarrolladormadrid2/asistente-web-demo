Cómo funciona

Abre el chat

Pulsa el botón flotante abajo a la derecha del chat y escribe lo que quieras hacer o preguntar.

El asistente actúa

Tu mensaje llega al agente, que lee el proyecto, hace los cambios y los versiona en el repositorio.

Despliegue y respuesta

Genera la publicación en GitHub Pages, la verifica y te responde en el propio chat con el resultado.

Preguntas frecuentes

¿Quién está detrás del chat?

Es un agente de OpenCode con acceso al código del proyecto. Tiene permiso para leer, editar y desplegar esta web siguiendo las directrices del repositorio.

¿Dónde se aloja la web?

En GitHub Pages, publicada desde la rama principal del repositorio público desarrolladormadrid2/asistente-web-demo.

¿Qué ocurre si el asistente no está conectado?

El chat necesita que el servidor local esté en marcha. Si ves "sin servidor", consulta el README del proyecto para arrancarlo.
